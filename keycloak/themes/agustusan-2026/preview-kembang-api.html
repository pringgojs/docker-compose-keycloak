Catatan teknis

  • Semua variasi tanpa JavaScript — murni CSS transform + opacity, dipercepat GPU. Tidak terpengaruh Rocket Loader.
  • Menghormati prefers-reduced-motion — animasi mati otomatis kalau pengguna menyetel gerak minimal di OS.
  • C4 paling ramai tapi juga paling banyak elemen (±70 node). Masih ringan, tapi C2 titik paling seimbang antara meriah dan tenang untuk halaman login.
