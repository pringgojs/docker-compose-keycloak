Mode gelap otomatis. Tidak ada tombol pengubah tema di halaman preview — tampilan mengikuti preferensi sistem operasi Anda (prefers-color-scheme / Tailwind darkMode: 'media'). Ubah tema terang/gelap di pengaturan sistem untuk melihat mode gelap.
